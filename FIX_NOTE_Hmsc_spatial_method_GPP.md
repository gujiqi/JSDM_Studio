# Spatial method help fix

The Hmsc spatial-method help text has been corrected.

## Options

- Full: full spatial model. Usually appropriate for smaller datasets.
- NNGP: nearest-neighbour Gaussian process. Usually safer/faster for larger spatial datasets.
- GPP: Gaussian predictive process / reduced-rank spatial approximation.

The previous help text mentioned only NNGP and could make it look as if GPP was missing or unsupported.
