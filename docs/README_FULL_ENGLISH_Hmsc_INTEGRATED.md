# FULL_ENGLISH_FIXED Hmsc panel integrated

This package keeps the full multi-engine workbench, but the Hmsc Workflow tab has been replaced with the older working Hmsc interface from `JSDMStudio_FULL_ENGLISH_FIXED(1).zip`.

Important:
The uploaded `JSDMWorkbench_project_Hmsc_20260521_233645.zip` was a Hmsc run-results ZIP, not the application source package. It contained fitted results and output folders, but no `app.R`, so it could not be used as the base for UI panels. The non-Hmsc panels were therefore kept from the latest full workbench app package available in this workspace.

Test:
1. Run `Check_R_Syntax.bat`.
2. Run `Launch_in_default_browser.bat`.
3. Open `Hmsc Workflow`.
