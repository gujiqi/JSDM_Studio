# sjSDM / s-jSDM complete workflow update

This build adds an independent s-jSDM Workflow with detailed parameters, checks, output archive, project recommendation support and model comparison support.

Key sections: data upload, data check, model settings, regularization and biotic structure, DNN/optimizer settings, spatial/ANOVA/metacommunity settings, prediction/importance/outputs, run and results.

Output folders: used_config.yml, inputs/, models/, tables/, weights/, importance/, anova/, internal_structure/, predictions/, plots/, diagnostics/, results/README_sjSDM_results.txt and report/sjSDM_report.html.

This remains a SAFE build; full fitting should be connected through a production sjSDM engine adapter.
